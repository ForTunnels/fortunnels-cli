# ForTunnels CLI

ForTunnels — аналог ngrok, который работает в РФ: даёт localhost публичный адрес для демонстраций, тестирования вебхуков и доступа к HTTP/HTTPS, TCP- и UDP-сервисам.

[English version](README.md) · [Сайт](https://fortunnels.ru/) · [Документация](https://fortunnels.ru/docs)

## 1. Установите клиент

Для установки CLI не нужен Go.

**macOS и Linux с Homebrew:**

```sh
brew install fortunnels/fortunnels/fortunnels
```

**Windows с Chocolatey** (запустите PowerShell от имени администратора):

```powershell
choco install fortunnels
```

Без пакетного менеджера [скачайте готовый клиент](https://fortunnels.ru/#downloads) для вашей ОС и архитектуры. Распакуйте архив и поместите `fortunnels` (на Windows — `fortunnels.exe`) в каталог из `PATH`. Контрольные суммы архивов есть в файле [SHA256SUMS.txt](https://fortunnels.ru/landing-assets/downloads/SHA256SUMS.txt).

## 2. Откройте первый туннель

Запустите веб-приложение на порту 8000, затем выполните:

```sh
fortunnels 8000
```

Откройте публичный HTTPS-адрес, который выведет CLI. Запросы по этому адресу попадут на `localhost:8000`. Не закрывайте клиент, пока нужен туннель. Чтобы остановить его, нажмите Ctrl+C. Если гостевой доступ включён, HTTP-туннель можно попробовать без регистрации.

## 3. Зарегистрируйтесь и подключите аккаунт

[Зарегистрируйтесь бесплатно](https://fortunnels.ru/?register=1), чтобы управлять туннелями в личном кабинете. CLI-токены доступны на тарифе Free.

1. Откройте [настройки личного кабинета](https://fortunnels.ru/dashboard/settings) и создайте CLI-токен. Полное значение токена показывается один раз.
2. Скопируйте готовую команду из личного кабинета или подставьте свой токен вместо `YOUR_CLI_TOKEN`:

   ```sh
   fortunnels config add-authtoken YOUR_CLI_TOKEN
   ```

3. Снова запустите `fortunnels 8000`. Клиент подхватит сохранённый токен, а новый туннель появится в личном кабинете.

Не публикуйте токен. Для автоматизации передавайте его через `FORTUNNELS_TOKEN` или `-token-file`, чтобы не указывать секрет в самой команде.

## Справочник CLI

| Задача | Команда |
| --- | --- |
| Открыть локальное веб-приложение или API | `fortunnels 8000` |
| Принимать вебхуки в локальном приложении | `fortunnels http 3000` |
| Направить запросы в локальный HTTPS-сервис | `fortunnels https 8443` |
| Открыть локальный TCP-сервис | `fortunnels tcp 22` |
| Открыть локальный UDP-сервис | `fortunnels udp 9000` |
| Проверить локальную конфигурацию с токеном | `fortunnels config check` |
| Посмотреть все флаги | `fortunnels --help` |

Перед запуском TCP- или UDP-туннеля подключите аккаунт через CLI-токен. Для подключения используйте хост и порт, которые выведет клиент. Если указан только порт, для HTTP, HTTPS и TCP используется `localhost`, а для UDP — `127.0.0.1`. Чтобы задать точный адрес, используйте `-local host:port`, например `fortunnels -local '[::1]:8000'`.

- `-watch` отслеживает состояние туннеля; `-watch-interval 5s` меняет интервал опроса.
- `-token-file` и `-token-stdin` передают токен для одного запуска. Явно переданный токен имеет приоритет перед сохранённым.
- `-udp-listen` и `-udp-dst` вместе включают обратный режим UDP. Параметры транспорта описаны в [документации CLI](https://fortunnels.ru/docs/cli).

Если публичный адрес возвращает **502**, сначала проверьте, открывается ли `http://localhost:8000` на вашей машине. При ошибке авторизации запустите `fortunnels config check`. Эта команда проверяет только локальный файл. Если срок действия токена истёк или токен отозван, создайте новый в настройках личного кабинета.

## Сборка из исходников

Склонируйте этот репозиторий и запустите в его корне команду с версией Go, указанной в [go.mod](go.mod):

```sh
go build -o fortunnels ./cmd/client
```

На Windows используйте `go build -o fortunnels.exe ./cmd/client`.
